# Téo, Engenheiro de Campo

Arte do Ludo.ai. O retrato vem da ilustração usada no estudo. O sprite parado foi
gerado a partir dela no Image Generator, tipo Sprite. O Sprite Generator usou esse
mesmo sprite como primeiro quadro para a caminhada e o disparo, com o modelo Hydra.

- [Conceito](https://storage.googleapis.com/ludo-assets/f7e731ad24abdb563723918bd79078d7.webp)
- [Sprite de referência](https://storage.googleapis.com/ludo-assets/9bdae3eee1ba0bd5b000b35cc8b18116.webp)
- [Arte dos quatro ícones](https://storage.googleapis.com/ludo-assets/9f9195534352200f7f3297214f49671a.webp)

As folhas exportadas tinham 36 quadros de caminhada e 30 de disparo. Os quadros
foram alinhados em células de 320 × 320 com transparência. O sprite padrão foi
espelhado para usar a mesma convenção de direção dos demais heróis.
