# Class ability icons

Illustrated fantasy atlas with dark painted interiors and ornate gold frames, matching the existing Shadowbolt, Corruption, Charge and Consecration icons. ClassIcons.png is a 4x4 atlas; the first ten cells are used in row-major order through AtlasTexture resources. Empty cells are reserved. Generated using the original game icons as visual references. Charge, Holy Light and Consecration reuse the game's original PNG icons.
